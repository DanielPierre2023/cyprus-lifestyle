# Cyprus Lifestyle — Brand ("Aegean Nocturne")

The Mediterranean after dark: obsidian ground, alabaster type, copper raised to
foil. Glamour by restraint. Dark for the masthead/hero/footer; light, readable
ivory for the reading.

## Palette
| Token | Hex | Role |
|-------|-----|------|
| Obsidian | `#0B0E11` | Primary ground (dark bands) |
| Alabaster | `#F4EFE6` | Type on dark; ground for light editions |
| Paper | `#F6F1E7` | Reading surface |
| Ink | `#16181C` | Body type on light |
| Copper | `#B0703A` / on-light `#96551E` | The signature accent |
| Gold | `#C9A24C` | Foil highlight, rules, labels on dark |
| Champagne | `#E4D2AC` | Secondary light on dark |
| Aegean | `#123A4A` | Depth, duotone imagery |

**Copper foil (CSS):**
`linear-gradient(105deg,#7A481E,#C1823F,#F2D9A0,#BE7C39,#8A5622,#E7C589,#6E4019)`
clipped to text. Print: copper foil / PMS 876 C. Never flatten to muddy orange.

## Typography
| Face | Role | Notes |
|------|------|-------|
| **Bodoni Moda** | Masthead & headlines | High-contrast Didone — the luxury-press signal |
| **Jost** | Labels, nav, captions, UI | Geometric sans (Futura lineage) |
| **Lora** | Body & long-form | Readable serif for reading surfaces |
| **Aref Ruqaa** | Arabic display | Calligraphic; used for the Arabic edition |
| **Amiri** | Arabic body | Elegant naskh |

All are free, open-source Google Fonts — no licensing cost for print or web.

## Layout principles
- Dramatic scale contrast; generous space; strict grid.
- One metal (copper/gold) does the luxury work — no second accent.
- Numbers in tabular figures. British spelling in English; euro figures.
- Right-to-left for Arabic: layout mirrors, display face switches to Aref Ruqaa.
